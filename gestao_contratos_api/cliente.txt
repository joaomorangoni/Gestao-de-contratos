# Cliente Python - Sistema de Gestão de Contratos

## Descrição

O arquivo `cliente_terminal.py` foi desenvolvido para funcionar como um cliente em Python capaz de consumir a API REST do sistema de Gestão de Contratos.

O programa permite que o usuário interaja com o backend diretamente pelo terminal, realizando requisições HTTP para a API Flask.

O cliente não acessa o banco de dados diretamente. Todas as operações são enviadas para a API, que é responsável por validar as informações, executar as regras de negócio e realizar a persistência dos dados.
